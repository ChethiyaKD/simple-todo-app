# Simple Todo App

A simple and elegant Todo application built with React, TypeScript, Vite, and HeroUI.

## Features

- **Add Tasks**: Easily create new tasks.
- **Edit Tasks**: Update existing task titles and descriptions.
- **Toggle Status**: Mark tasks as complete or incomplete.
- **Delete Tasks**: Remove tasks you no longer need.
- **Search Tasks**: Quickly filter your tasks to find what you need.
- **Authentication**: Secure access to your own tasks.
- **Responsive Design**: Works well across different devices.

## Environment Variables

To run this project, you will need to add the following environment variables to your `.env` file in the `client` directory:

```env
VITE_BASE_URL="http://localhost:5000" # Replace with your actual API endpoint
```

## Running Locally

1. Install dependencies:

   ```bash
   yarn install
   ```

2. Start the development server:
   ```bash
   yarn dev
   ```
